# Support

## Where to Ask for Help

- Usage questions and design discussion: GitHub Discussions (preferred once enabled).
- Defect reports: GitHub Issues.
- Security vulnerabilities: GitHub Security Advisories only (see `SECURITY.md`).

## Routing Guide

Open an issue when:

- You can describe a reproducible bug.
- You have a concrete feature request with acceptance criteria.

Open a discussion when:

- You need architectural guidance.
- You want feedback before implementation.
- You want to propose broad direction changes.

## Response Expectations

- Best-effort response for community support requests.
- No guaranteed SLA for general support.
- Security reports follow SLA in `SECURITY.md`.
